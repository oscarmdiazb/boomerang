# Boomerang

A small desktop web app for scheduling messages back to yourself when collaborators across time zones are awake.

**Live app:** [oscarmdiazb.github.io/boomerang](https://oscarmdiazb.github.io/boomerang)

## What it does

Write a message → pick when it should come back to you → at that time, get a desktop notification with a one-click "Copy" button. Paste into WhatsApp Desktop (or wherever) and send.

Built for the Berlin ↔ Bogotá workflow but works for any time-zone pair.

## Install as a desktop app

1. Open the live URL in Chrome or Edge.
2. Click the install icon (⊕) in the address bar.
3. The app gets its own window, dock/Start menu icon, and notifications work even when minimized.

## Data

All messages are stored in your browser's local storage. Nothing is sent anywhere. Clearing browser data clears the queue.
